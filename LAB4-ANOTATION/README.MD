# Spring Annotation-Based Configuration Lab 4

## Project Description

This project demonstrates Spring Core IoC and Dependency
Injection using Java Annotation-Based Configuration instead
of XML configuration.

## Technologies Used

- Java 17
- Maven
- Spring Framework 6.2.7
- IntelliJ IDEA
